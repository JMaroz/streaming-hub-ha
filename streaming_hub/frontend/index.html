Stato Integrazione TMDb In controllo...

Senza una chiave API TMDb valida, Streaming Hub utilizza motori fallback (Cinemeta/TVmaze) che non includono i loghi e la disponibilità delle piattaforme streaming (Netflix, Prime Video, Disney+, ecc.).
